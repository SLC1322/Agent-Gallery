C700 Deploy Walkthrough
genai.mil
✓
Your agent is now ready.
  1. 1
    Sign in via certificate

    Go to genai.mil and authenticate with your CAC or PIV certificate.

  2. 2
    Click Agents

    In the left sidebar, click the Agents link to open the agent library.

  3. 3
    Click New Agent

    Hit the blue + New Agent button in the top area of the library.

  4. 4
    Bypass Agent Designer

    When the modal appears, choose Bypass Agent Designer for full control of the agent card.

  5. 5
    Select blank agent card

    Pick the blank card. You will paste everything from C700 into this card.

  6. 6
    Copy each field from C700

    On the C700 hero page, copy the agent name, system prompt, and description into the matching fields.

  7. 7
    Upload knowledge files

    Click the + under Knowledge to upload desk guides, SOPs, or reference docs the agent needs.

  8. 8
    Add sub-agents

    If the agent uses sub-agents, click + to wire each one in. Repeat for every sub-agent listed on the hero page.

  9. ✓
    Done

    Your agent is now ready. Go run it on genai.mil.
